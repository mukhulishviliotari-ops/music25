### ✨ Features

* 🎶 **Interactive Audio Player:** Custom player with smooth controls and progress tracking.
* 📱 **Responsive UI:** Fully responsive layout with smooth hover effects and CSS animations.
* 🔍 **Track Search & Discovery:** Search and browse through music collections cleanly.
* 🎧 **Playlist Management:** Create and organize tracks into dynamic playlists.
